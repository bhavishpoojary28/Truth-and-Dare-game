# 🎭 Truth & Dare with Friends

A fun, safe, and engaging web app for playing Truth & Dare with friends!

## ✨ Features

### 🎯 Solo Mode
- Play by yourself
- Choose between Truth questions and Dare challenges
- Track your stats (number of truths vs dares completed)
- Perfect for breaking the ice or just having fun

### 👥 Friends Mode
- Add 2-10 players
- Automatic player rotation
- Track game rounds
- Each player gets assigned Truth or Dare challenges
- Great for parties, gatherings, and group activities

### 📱 Mobile-Friendly Design
- Responsive layout that works on all devices
- Bright, playful colors with gradient animations
- Smooth transitions and hover effects
- Glass-morphism UI design

### 🛡️ Safe Content
- All truth questions are lighthearted and appropriate
- Dare tasks are fun but safe (no harmful or NSFW content)
- Suitable for all ages (teens and up)
- 30+ unique truth questions and 30+ unique dare tasks

## 🚀 How to Use

1. **Open the App**: Double-click `truth-dare-app.html` to open in your browser
2. **Choose Mode**: 
   - **Solo Mode**: Play alone
   - **Friends Mode**: Add friends to play together
3. **Add Players** (Friends Mode only):
   - Enter player names one by one
   - Remove players if needed
   - Need at least 2 players to start
4. **Play the Game**:
   - Choose Truth or Dare
   - Complete the challenge
   - Click "Next" for another round

## 🎮 Game Flow

### Solo Mode
1. Welcome → Game Mode → Solo Game
2. Choose Truth/Dare → View Question/Challenge
3. Click "Next" to get another challenge
4. Stats are tracked automatically

### Friends Mode
1. Welcome → Game Mode → Add Players → Friends Game
2. Current player chooses Truth/Dare
3. Complete the challenge
4. Automatically moves to next player
5. Tracks rounds and player count

## 🔧 Technical Details

- **Frontend Only**: Pure HTML, CSS, and JavaScript (no backend required)
- **No Dependencies**: Works offline, no internet connection needed
- **Browser Compatibility**: Works in all modern browsers
- **File Size**: Single HTML file (~25KB)

## 🎨 Customization Options

### Adding More Questions/Dares
Edit the `truthQuestions` and `dareTasks` arrays in the JavaScript section:

```javascript
const truthQuestions = [
    "Your new truth question here...",
    // Add more questions
];

const dareTasks = [
    "Your new dare task here...",
    // Add more dares
];
```

### Styling Changes
- Modify CSS variables in the `<style>` section
- Change colors, fonts, or animations
- Adjust mobile responsiveness
